# Jie Fang Academic Homepage

Personal academic homepage for Jie Fang, an undergraduate researcher at Renmin University of China working across economics, artificial intelligence, and data science.

The information architecture is inspired by [RayeRen's AcadHomepage](https://github.com/RayeRen/acad-homepage.github.io). This implementation is a lightweight static site and can be deployed directly with GitHub Pages.
